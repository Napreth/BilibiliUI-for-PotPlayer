# 字幕与弹幕渲染

文本统一使用 libass 0.17.5。现有两阶段分类保留，分类与可渲染能力分别判断：标准 ASS／SSA 的高级组可播放；B 站 Mode 7 经 DanmakuFactory 转成 ASS 后可播放。Mode 8／9 和其余未支持的高级协议保持禁用。转换边界见 [弹幕转换说明](danmaku-conversion.md)。

## 数据与时钟

- ASS／SSA 保存原始脚本头、样式、画布、事件字段、Layer 和原始顺序，保留事件前后的内嵌字体段。内封 ASS 经 FFmpeg 保留这些信息，并提取 TTF／OTF／TTC 字体附件。同源同类事件保留 Layer 与同层顺序；字幕为局部遮挡单独合成，普通弹幕进入统一排布。
- PotPlayer 的位置报告可能约半秒才更新一次。`PlaybackClock` 用宿主单调时钟在报告之间插值，按实际报告间隔调整外推上限；暂停冻结、确认停止后清空、跳转重新定位，报告长期不前进时停止外推。位置报告按 IPC 返回时刻计时；新报告发现插值走快或走慢时，以有界速度平滑纠偏，避免字幕持续提前，也不倒退或重建已有弹幕。读取暂时失败、短暂的停止状态和落后的重复报告保留现有实例，避免误判跳转后整批重建。文本层随约 15 ms 的 UI 调度更新，不再以 33 ms 门限跳过隔轮刷新。
- 标准高级 ASS 在插值后的媒体时间调用 `ass_render_frame`，仍由 libass 解释作者的运动、变换、透明度、裁剪、卡拉 OK 和绘图。
- SRT 等普通文本生成 ASS 字幕，主副字幕按现有底部布局叠放。ASS／SSA、XML、JSON 的普通弹幕统一进入排布与碰撞链路，生成带起止时间的 `move`／`pos` 事件，交给 libass 连续渲染。未改变的脚本复用轨道，字宽按事件和字号缓存，不再每一帧释放并解析相同的运动脚本。
- B 站字幕 JSON 支持 `from`／`to`／`content` 数组及 `body` 包装，保留原始起止时间，作为字幕参与选轨和局部遮挡。
- 普通弹幕关闭“速度同步播放倍数”时，按实际经过的播放速度分段累计运动时间；临时切换倍速不会重新按当前倍率计算整条弹幕的年龄，避免横向跳动。暂停不累计时间，跳转清除旧的速度历史；开启同步时按媒体时间运动。
- `DanmakuPlayback` 维护已入场实例和播放游标，只在事件到达时尝试一次排布。滚动实例从画面右边缘进入，反向实例从左边缘进入；占用冲突时丢弃该次事件，不在后续帧重排历史事件。加载／启用来源和跳转只等待目标时间之后的新事件，避免从画面中间补播。
- Mode 7 在加载工作线程中交给 DanmakuFactory 的 ASS 写入器。转换轨保留原始事件，渲染使用转换后的 ASS 事件；普通、已转换高级、转换失败／未支持高级各自列出。播放、暂停和跳转不重复转换。
- 普通文字中的反斜杠和花括号转成全角字面字符，避免被当作 ASS 控制标签；只有标准 ASS 来源保留覆盖标签。

## 样式与开关

普通文本及普通弹幕使用界面中的字体、大小、颜色、透明度、描边和背景设置。普通 ASS 以该来源最常见的字号为基准归一化，并保留事件间的相对字号差异，避免将源画布字号再次放大；XML／JSON 以常规字号 25 为基准。普通 ASS 弹幕采用统一的显示区域、排布、速度和类型过滤，不再同时播放绕过这些选项的原始 ASS 轨道；显示区域也裁剪实际字形，防止大字号越界。白色显示和按源颜色过滤相互独立，不修改源事件。

普通弹幕默认采用 100% 字号、常规字重和轻描边。100% 是 25 个逻辑像素，字形和描边按窗口 DPI 换算；默认不随视口尺寸改变。启用随屏幕缩放后，以视口逻辑高度应用网页端的分段字号曲线，保留来源的相对字号和自定义百分比；排布高度由字号、换行数与小幅逻辑像素留白确定。旧默认预设迁移到这一基准，其他自定义参数保留。字幕描边和作者定义的 ASS 字幕／高级特效沿用各自配置。

普通文本字幕默认使用微软雅黑常规白字，不带弹幕描边；字号为画面高度的 48/1080，独立于弹幕的逻辑像素基准。灰底留出约 1.5 倍字号的行高，左右内边距为 12 个逻辑像素、圆角半径 4 个逻辑像素，按窗口 DPI 换算。原有默认预设可迁移，已自定义的字体、字号和效果保留；ASS 作者样式不套用此预设。

弹幕样式以入场时的快照为准：已出现的弹幕保持原字体、字号、颜色、透明度、描边／背景、区域、位置、速度及速度同步策略直到结束。来源开关及滚动／固定／彩色／高级过滤即时移除对应的在屏事件；弹幕总开关立即清除全部弹幕实例。重新开启这些开关不会补回已移除或错过的事件。原生 ASS 高级事件继续保留作者编排，来源和高级过滤控制其即时可见性。字幕设置继续即时更新。

标准 ASS 字幕与高级 ASS 特效保持作者的字体、坐标、时间及特效，不将普通弹幕的字号／速度／区域设置强行套到源脚本上。普通弹幕和高级 ASS 均受 D 总开关控制，C 控制主副字幕。

显示区域为 100% 时提供密度选项，低于 100% 时使用正常策略但保留上次选择。正常档保留绝对权重至少为 3 的事件，较多档将门限降为 2，两档分别在滚动、顶部固定、底部固定的碰撞池内检测，避免固定弹幕与滚动弹幕互相独占整行。重叠档采用门限 2，先尝试第一组可用空间，不足时依次尝试第二、第三组；组内仍检查包围盒和追尾，组间允许交叠，三组均无空间时拒绝入场。入场实例有统一资源上限，密度变化不重排或移除在屏实例；原有分组随实例保留到播放结束。

滚动基础时长按视口和文字的逻辑宽度采用分段范围与非线性曲线，再除以用户速度系数；同一逻辑尺寸在不同 DPI 下具有相同基础时长。固定弹幕显示 4.5 秒，不使用滚动速度系数。时长只在入场时计算，窗口变化或设置修改不会重新定时已有弹幕。详细参考范围见[网页端弹幕行为](algorithms/bilibili-danmaku-behavior.md)。

权重读取自 JSON 的 `weight` 或 XML 的可选 `weight` 属性。缺失或无效时不生成随机分数、不作权重筛选，因此这类来源的正常与较多档可能相同；本项目不提供 B 站云端评分模型。上述门限参考[B 站播放器的密度与权重判定](https://s1.hdslb.com/bfs/static/player/main/core.0a5e425c.js)，高级 ASS 仍按作者坐标渲染，重叠选项不重排高级效果。

图像字幕 PGS／VobSub 继续使用 PotPlayer。使用自己的文本层时隐藏原生文本字幕，结束后恢复偏好，避免重复显示。

## 播放画布与黑边

普通弹幕的入场边缘、排布范围和显示区域以完整视频视口为准，包含比例适配产生的上下和左右黑边，范围不延伸到侧栏。候选位置同时覆盖视口高度和现有文字包围盒边缘，使小字号能够使用大字号之间的空隙；在同组通过碰撞检测的位置中优先选择负载较低的位置，同负载时打散选择，既使用下半屏，也避免入场顺序与位置关联而形成斜列。固定弹幕保持顶部／底部锚点。字幕与作者编排的 ASS 仍按视频实际画面尺寸渲染，再合成到该画面在视口中的位置；普通文本字幕的字号和底边距也相对于实际画面计算。

防挡字幕不缩小入场区域。libass 字形范围按实际可见像素测量，排除位图中不对称的透明留白，再合并相邻字形并添加对称的上下内边距，使文字在半透明灰底中垂直居中；互相远离的字幕块分别处理。合成时仅替换灰底范围内的弹幕像素，再绘制字幕。弹幕实例、轨迹、年龄与样式快照保持不变，经过灰底时暂时隐藏，离开后继续显示；字幕结束或关闭时遮罩立即消失。标准 ASS 字幕同样按实际字形遮挡，不改写源事件或作者坐标。

## 合成与生命周期

`AssScene` 管理选中源和每帧生成的脚本，`LibassRenderer` 管理轨道和字体，`BilibiliAss.dll` 仅封装公共 libass API。ASS 位图按顺序合成为预乘 BGRA，再交给现有透明、穿透输入的窗口。普通弹幕覆盖完整视频视口，字幕与作者编排的 ASS 按实际画面矩形合成；播放器菜单和控制栏保持在其上方。

普通弹幕按“滚动 → 固定”合成，固定层始终在滚动层上方；各层分别渲染媒体时间和独立动画时间的事件，防止速度同步分组改变图层顺序。字幕灰底及字幕最后合成，在对应范围内覆盖弹幕。

每个播放器独立持有上下文。修改选择时释放旧轨道；更换媒体时重建字体库，防止附件字体跨媒体污染；关闭播放器时释放轨道、渲染器和字体库。字体附件限制为每个 16 MiB、合计 32 MiB，脚本限制为 32 MiB。没有额外进程或托盘。

## 依赖构建

`build/libass.ps1` 从校验过的源码构建 libass，使用 FreeType 2.15.0、HarfBuzz 15.0.0 和 FriBidi 1.0.17，固定 Meson／Ninja 版本与选项。字体依赖静态链接于共享 libass，采用 DirectWrite 字体提供器；禁用可选 iconv 自动探测，输入统一 UTF-8。

安装包包含原始源码、构建脚本和选项。许可说明位于 [LICENSES](../LICENSES/README.md)。

## 开发验证

`scripts/new-danmaku-sample.ps1` 用开发环境的 ffmpeg 生成深色 60 fps 视频和同名普通 ASS 弹幕，供区域、透明度、过滤及运动验证；生成工具不参与播放器运行。`BilibiliBehaviors.Tests.exe --timing-probe 输出.csv` 在播放器所在的交互会话只读采样原始与插值时间。回归检查另覆盖半秒量化采样、暂停、跳转、缓冲、变速连续性，以及 ASS／XML／JSON 的实际渲染像素。
