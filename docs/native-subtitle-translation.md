# 原生字幕翻译

实时字幕翻译复用 PotPlayer 的原生翻译扩展。引擎、账户、原文语言、目标语言及启用条件由 PotPlayer 原生设置管理；译文交给本项目的 libass 显示，保留现有字幕字体、位置和圆角灰底，原文与副字幕继续显示。

## 使用

1. 在“字幕和弹幕”中选择一条文本主字幕。
2. 打开“实时字幕翻译”，进入“PotPlayer 原生翻译设置”，启用并配置已有的翻译引擎和语言。
3. 开启本项目的“启用实时翻译”。未配置、扩展不兼容或没有返回结果时，原字幕继续显示，可检查原生设置后重试。

翻译默认关闭。文字由所选原生引擎处理；使用在线引擎时，其服务、账户要求和数据处理方式与该原生扩展一致。本项目不另选翻译服务，也不读取账户或密钥。

目前支持 `Extension/Subtitle/Translate` 中实现标准 `Translate(string Text, string &in SrcLang, string &in DstLang)` 接口的 UTF-8 AngelScript 扩展。含 `#include` 或非标准入口的扩展暂不适配；PotPlayer 内置 AI 翻译尚未验证此回传接口，不能保证兼容。图像字幕需先做文字识别。

## 处理与显示

```mermaid
flowchart LR
    A[文本主字幕] --> B[当前及未来十五秒内的有界字幕输入]
    B --> C[PotPlayer 原生翻译扩展]
    C --> D[播放器与会话校验]
    D --> E[现有 libass 字幕与灰底]
```

每次只提交当前及未来约十五秒内、最多八条字幕，不把整份来源交给原生翻译预读。缓存仅保存在内存中。译文沿用原字幕时间，迟到结果不会延长显示；切换媒体、主字幕或原生翻译设置时撤销旧会话。跳转后重新定位输入，后台等待不阻塞播放，失败后退避重试。

临时 SRT 包含会话标记及原文字节，适配层在调用原引擎前还原原文，避免原生文本缓存串用旧语言，以及 SRT 处理丢失换行或字面标签。原生翻译首次初始化使用不含可见文字的控制字幕，不调用翻译服务；之后实际字幕保持隐藏。译文另起一行，作者 ASS 的原字形与坐标保留，灰底继续参与弹幕局部遮挡。

桥接使用有长度限制的本地消息，校验播放器身份、会话代次和已提交原文。不读取剪贴板，不调用播放器私有函数地址。关闭时撤销回传，恢复可定位的原生来源或选中的外部字幕；无法恢复来源时以空白输入替换临时内容，退出后清理临时文件。

## 扩展文件与恢复

安装程序保留翻译脚本原文件名，在外层转发初始化、语言列表、账户设置及翻译入口，原生引擎选择和账户存储继续有效。回传库 `BilibiliTranslation.dll` 同时放在翻译脚本目录。

原文件字节和校验值保存在安装恢复目录，升级沿用；卸载只还原仍与本项目适配版本匹配的文件，保留用户或 PotPlayer 后续更新的内容。恢复备份缺失或损坏时中止相关卸载步骤，保留恢复材料。
